# CursorSpawn

**다중 모니터 환경에서, 새로 뜨는 창이 항상 마우스 커서가 있는 모니터에 나타나게 해주는 Windows 트레이 유틸리티입니다.**

여러 모니터를 쓰다 보면 새 프로그램을 실행했을 때 커서가 없는 엉뚱한 모니터에 창이 뜨는 경우가 많습니다. CursorSpawn은 그런 창을 감지해서 커서가 위치한 모니터 정중앙으로 자동으로 옮겨줍니다. 별도 설정 없이 설치 후 트레이에 상주하며 조용히 동작합니다.

> 이 저장소는 **설치 파일(릴리스) 배포 전용**입니다. 최신 설치 파일은 [Releases](../../releases/latest)에서 받으세요.

## 다운로드 / 설치

1. [Releases](../../releases/latest)에서 `CursorSpawn-Setup.exe`를 다운로드합니다.
2. 실행합니다. 설치 경로가 `Program Files`이므로 **관리자 권한(UAC 동의)**이 필요합니다.
3. 설치 완료 후 자동으로 실행되며, 시스템 트레이(알림 영역)에 파란 아이콘이 나타납니다.

### 요구 사항

| 항목 | 요구 사항 |
| --- | --- |
| OS | Windows 10 (2004 이상) / Windows 11 |
| 런타임 | [.NET 8 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/8.0) — 없으면 최초 실행 시 Windows가 설치를 안내합니다 |
| 아키텍처 | x64 |

## 주요 기능

- **커서 위치 기반 자동 재배치**: 새 창이 화면에 표시되는 순간, 마우스 커서가 있는 모니터의 정중앙으로 옮깁니다. 포커스는 빼앗지 않습니다.
- **최소화 복원 감지**: 이미 실행 중인 프로그램을 타스크바/바로가기로 다시 열어 복원할 때도 같은 방식으로 재배치합니다. 단순히 다른 창으로 포커스만 전환하는 경우(Alt+Tab 등)는 건드리지 않아 기존 다중 모니터 작업 배치를 방해하지 않습니다.
- **단축키 (Win+Shift+C)**: 현재 활성 창을 즉시 커서가 있는 모니터로 재배치합니다.
- **창 크기 모드 2종** (트레이 메뉴에서 전환)
  - **작게 (화면 정중앙)**: 창이 모니터 작업영역의 75%를 넘으면 비율을 유지한 채 축소해 정중앙에 배치합니다.
  - **전체화면**: 대상 모니터 기준으로 최대화합니다.
- **활성창 제외 등록**: 실행 중인 프로그램 목록에서 원하는 프로그램을 선택해 재배치 대상에서 제외할 수 있는 전용 관리 화면을 제공합니다.
- **기능 켜기/끄기**: 트레이 아이콘 좌클릭 또는 메뉴에서 즉시 일시정지·재개할 수 있습니다(아이콘 색으로 현재 상태 표시).
- **시작 프로그램 등록**: Windows 로그인 시 자동 실행 여부를 토글할 수 있습니다.
- **관리자 권한 창 제어**: 작업 관리자, 레지스트리 편집기 등 관리자 권한으로 뜬 창은 Windows 보안 정책(UIPI)상 일반 권한 프로그램이 위치를 옮길 수 없습니다. 트레이 메뉴의 "관리자 권한으로 재시작"으로 CursorSpawn 자체를 관리자 권한으로 재시작하면 이런 창도 재배치할 수 있습니다.
- **단일 인스턴스**: 중복 실행되지 않으며, 다중 DPI(배율이 다른 모니터 조합) 환경에서도 좌표 계산이 왜곡되지 않습니다.

## 트레이 메뉴

| 메뉴 | 동작 |
| --- | --- |
| 기능 활성화 (또는 트레이 아이콘 좌클릭) | 재배치 기능 일시정지 / 재개 |
| 창 크기 › 작게 (화면 정중앙) / 전체화면 | 새 창을 배치할 때의 크기 모드 선택 |
| 활성창 제외 등록 | 실행 중인 프로그램 / 제외 등록된 프로그램을 보여주는 관리 화면 |
| 시작 프로그램 등록 | Windows 로그인 시 자동 실행 여부 토글 |
| 관리자 권한으로 재시작 | UAC 동의 후 관리자 권한으로 재시작 |
| 종료 | 프로그램 종료 |

## 제거

Windows 설정 → 앱 → CursorSpawn → 제거를 실행하면, 설치 시 등록했을 수 있는 시작 프로그램 등록(레지스트리 또는 예약 작업)까지 함께 정리됩니다.
